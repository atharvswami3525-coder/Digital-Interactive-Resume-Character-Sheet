Cozy Corner — Hot & Cold Coffee & Softea Chocklet CafeCozy Corner is a modern, feature-rich web application for a specialty cafe serving handcrafted hot coffee, artisanal cold brews, and signature Softea Chocklet drinks, complete with online ordering and instant loyalty rewards.   ☕ FeaturesOnline Ordering: Browse and order handcrafted hot coffees, cold coffee frappes, signature soft chocolate drinks, and desserts.   Cozy Beans Loyalty Program: Earn loyalty rewards and discounts with every order placed.   AI Integration: Built-in server-side Gemini AI capabilities powered by the Google Gen AI SDK.   Responsive Design: Styled with Tailwind CSS and Framer Motion animations for a smooth, cozy user experience.   🛠️ Tech StackFramework: React 19 with TypeScript   Build Tool: Vite   Styling: Tailwind CSS v4   Icons & Animation: lucide-react, motion   Backend / Server: Express with TypeScript (tsx)   AI SDK: @google/genai   ⚙️ Environment VariablesThe application requires the following environment variables (automatically injected in runtime environments like AI Studio or configured via .env):   GEMINI_API_KEY: Required for Gemini AI API calls.   APP_URL: The URL where this applet is hosted, used for self-referential links, OAuth callbacks, and API endpoints.
