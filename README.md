# 🛡️ Heroic Dev Dossier — Pure HTML RPG Resume & Character Sheet

A **100% Pure HTML** interactive developer resume and RPG character dossier built entirely using native HTML5 tags, semantically structured elements, and built-in browser features—**zero CSS styles, zero JavaScript frameworks, and zero external dependencies**.

---

## 🌟 Overview

This project showcases how far you can push raw HTML5 to build an engaging, interactive user interface. By relying on native HTML attributes and elements (`<details>`, `<summary>`, `<meter>`, `<progress>`, `<dialog>`, `<datalist>`, and `<form>`), the browser handles interactivity, data input, collapsing panels, and progress displays natively.

---

## ✨ Features & Pure HTML Mechanics

- **🎮 Dynamic HP/MP & XP Bars:** Uses native `<progress>` elements to represent energy levels and project completion status.
- **📊 Attribute & Skill Meters:** Uses native `<meter>` tags with defined `min`, `max`, `low`, `high`, and `optimum` ranges to display technical stat distributions.
- **📂 Interactive Collapsible Modules:** Uses nested `<details>` and `<summary>` elements to create collapsible quest logs, job history, and inventory inspect screens.
- **💬 Native Modal Popups:** Incorporates native `<dialog>` tags for viewing inspectable badges and achievements.
- **🔍 Auto-Complete Search & Select:** Utilizes `<datalist>` to provide built-in, native auto-completion for skill selection.
- **📋 Structured Tables & Fieldsets:** Organizes skill trees, equipment tables, and contact modules using `<fieldset>`, `<legend>`, `<thead>`, `<tbody>`, and `<tfoot>`.
- **♿ 100% Accessible & Lightweight:** Fully accessible via keyboard navigation, screen-reader friendly, and loads instantly on any web browser.
