🌟 About the Project

Cozy Corner is a café website concept designed to bring the warmth of a neighborhood coffee shop into the digital world.

From browsing the menu to placing an order and earning loyalty points, customers can enjoy a smooth and engaging experience while discovering their favorite drinks.

The project combines an attractive user interface with practical café features, including online ordering, customer accounts, and a loyalty rewards program.

🚀 Getting Started

Follow these steps to run the project locally.

Prerequisites

Install the following:

Node.js (a currently supported LTS version)
npm or another compatible package manager
Git
1. Clone the Repository
git clone <YOUR_REPOSITORY_URL>
cd cozy-corner

2. Install Dependencies
npm install

3. Configure Environment Variables

Create a .env.local file in the project root using .env.example as a guide.

Example:

DATABASE_URL=
AUTH_SECRET=
PAYMENT_PROVIDER_KEY=
PAYMENT_PROVIDER_SECRET=


Use the actual environment variable names required by your application. Never commit real secrets or API keys to GitHub.

4. Start the Development Server
npm run dev


Open the local URL displayed in your terminal, typically:

http://localhost:3000


Note: Database, authentication, and payment features require their corresponding services and credentials to be configured.

🔒 Security and Reliability

The application should follow security best practices:

Validate orders and prices on the server.
Protect customer accounts and administrator routes.
Verify payment status through trusted server-side mechanisms.
Store secrets in environment variables.
Prevent unauthorized manipulation of loyalty points.
Collect and store only necessary customer information.
Never store raw payment card details.
